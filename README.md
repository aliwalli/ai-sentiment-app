#  Sentica AI - Sentiment Analysis Dashboard

Full-stack web application that leverages a Transformer Model (DistilBERT) to analyze text sentiment in real-time.

## Tech Stack

* **Backend:** Python, Flask
* **AI / NLP:** Hugging Face Transformers, PyTorch, DistilBERT
* **Frontend:** HTML5, CSS3, JavaScript (Fetch API)
